CppHead

A high-performance C++23 command-line utility for fast, local-first file streaming.

View on GitHub Quick Start

Overview

CppHead is a lightweight, zero-cost abstraction file streaming utility built from first principles. Optimized with Clang and backed by comprehensive GoogleTest suites and built-in performance benchmarks, it delivers high execution throughput for modern engineering workflows.

Features

  • Modern C++23: Written using state-of-the-art C++ standards.
  • Clang Optimized: Built and tuned explicitly under Clang for maximum performance.
  • Automated Workflows: Seamless PowerShell scripts (build.ps1, install.ps1) handling compilation, unit testing, benchmarking, and deployment to `$HOME/bin`.
  • Integrated Testing & Benchmarking: GoogleTest integration and latency/throughput tracking harness.

Quick Start & Installation

Clone the repository and run the install script to build the project, verify tests, and deploy head directly to your user path:

git clone https://github.com/cschladetsch/CppHead.git
cd CppHead
.\install.ps1
